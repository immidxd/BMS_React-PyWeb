# 🔍 РОЗШИРЕНА СИСТЕМА ПОШУКУ BMS

## 📋 ОГЛЯД

Розширена система пошуку забезпечує інтелектуальний пошук по всіх полях товарів з підтримкою:
- **Токенізації** - розбиття запиту на окремі слова
- **Синонімів** - пошук схожих термінів
- **Нечіткого пошуку** - знаходження з помилками
- **Ранжування** - сортування по релевантності
- **Складних запитів** - пошук по комбінованих описах

## 🎯 МОЖЛИВОСТІ

### **1. Пошук по всіх полях:**
- Номер товару (`productnumber`)
- Клоновані номери (`clonednumbers`)
- Модель (`model`)
- Опис (`description`)
- Додаткові примітки (`extranote`)
- Бренд (`brandname`)
- Тип товару (`typename`)
- Колір (`colorname`)
- Стать (`gendername`)
- Стан (`conditionname`)
- Статус (`statusname`)
- Розміри (всі поля розмірів)

### **2. Інтелектуальна обробка:**

**Токенізація:**
```python
"Nike чорні кросівки" → ["nike", "чорні", "кросівки"]
"сітка; біла підошва, розмір 42" → ["сітка", "біла", "підошва", "розмір", "42"]
```

**Синоніми:**
```python
"чорні" → ["чорний", "black", "чорн", "темний"]
"кросівки" → ["кросівки", "кроси", "sneakers", "кросс"]
"шкіра" → ["шкіра", "шкір", "leather", "натуральна"]
```

**Нечіткий пошук:**
```python
"найк" → знайде "Nike" (схожість > 70%)
"кросі" → знайде "кросівки"
```

### **3. Ранжування результатів:**

**Ваги полів:**
- Номер товару: **10.0** (найвища)
- Модель: **8.0**
- Бренд: **7.0**
- Тип: **6.0**
- Колір: **5.0**
- Опис: **4.0**
- Стать: **4.0**
- Примітки: **3.0**

**Типи співпадінь:**
- Точне співпадіння: **×3.0**
- Співпадіння на початку: **×2.0**
- Містить термін: **×1.0**
- Схожість >70%: **×0.5**

## 🚀 ВИКОРИСТАННЯ

### **API Ендпоінти:**

#### **1. Глобальний пошук:**
```bash
GET /api/search/global?q=Nike+чорні&limit=5
```

#### **2. Розширений пошук:**
```bash
GET /api/search/advanced?q=Nike+чорні&limit=20&min_score=0.1
```

### **Параметри:**
- `q` - пошуковий запит (обов'язковий)
- `limit` - кількість результатів (1-100)
- `offset` - зміщення для пагінації
- `min_score` - мінімальний рейтинг релевантності

## 📝 ПРИКЛАДИ ЗАПИТІВ

### **Прості запити:**
```bash
# Пошук по бренду
"Nike" → знайде всі товари Nike

# Пошук по кольору
"чорний" → знайде чорні товари (+ black, темний)

# Пошук по типу
"кросівки" → знайде кросівки (+ кроси, sneakers)
```

### **Складні запити:**
```bash
# Комбінований пошук
"Nike чорні кросівки" → Nike + чорний колір + тип кросівки

# Пошук по опису
"сітка біла підошва" → товари з сітчастим верхом та білою підошвою

# Пошук по розміру
"розмір 42 шкіра" → шкіряні товари 42 розміру
```

### **Пошук з помилками:**
```bash
"найк кросі" → знайде "Nike кросівки"
"адідас біл" → знайде "Adidas білий"
```

## 📊 ПРОДУКТИВНІСТЬ

### **Оптимізації:**
- **Індекси БД** - на всіх полях пошуку
- **LIMIT/OFFSET** - пагінація результатів
- **Мінімальний score** - фільтрація нерелевантних результатів
- **Fallback** - простий пошук при помилках

### **Рекомендації:**
- Використовуйте `min_score >= 0.1` для фільтрації
- Обмежуйте `limit <= 50` для швидкості
- Кешуйте популярні запити на фронтенді
