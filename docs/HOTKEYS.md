# Гарячі клавіші BMS

`⌘` на macOS = `Ctrl` на Windows/Linux. Усі комбінації працюють на **будь-якій
розкладці** (українська/англійська) — код слухає фізичну клавішу (`e.code`), а не
надрукований символ.

Стан на 2026-08-10; кожен рядок перевірено в застосунку.

## Глобальні (працюють будь-де)

| Клавіші | Дія |
|---|---|
| `⌘` + `1`…`9` | Перейти на вкладку за номером (1 — Товари, 2 — Замовлення, 3 — Клієнти, …) |
| `⌘` + `→` | Наступна вкладка |
| `⌘` + `←` | Попередня вкладка |
| `⌘` + `K` | Фокус у рядок пошуку (текст одразу виділено — можна друкувати поверх) |
| `⌘` + `B` | Показати / сховати панель фільтрів |
| `⌘` + `R` | **Скинути всі фільтри** активної вкладки |

> `⌘R` діє на вкладку, яка **зараз на екрані**. Стандартне перезавантаження
> сторінки браузером при цьому заблоковано навмисно.

## Вкладка «Товари»

| Клавіші | Дія |
|---|---|
| `⌘` + `U` | Перемкнути фільтр «Тільки непродані» |
| `Esc` | Зняти виділення рядків (у режимі «Виділити») |

## Картка товару (відкрита)

| Клавіші | Дія |
|---|---|
| `<` (кома) | Попередня картка товару |
| `>` (крапка) | Наступна картка товару |
| `←` / `→` | Попереднє / наступне фото в галереї |
| `Esc` | Закрити картку |

Особливості:

- **Гортання карток закільцьоване** і виходить за межі сторінки: з останнього
  товару сторінки переходить на наступну, з кінця списку — на початок.
- У **режимі редагування** гортання карток вимкнено — щоб не загубити незбережене.
- Коли фото **розгорнуте на весь екран**, `<` / `>` гортають *фото*, а не картки
  (щоб не випасти з перегляду).
- `Esc` **розбирає стан шар за шаром**: спершу знімає виділення фото, потім
  виходить з режиму редагування, і лише тоді закриває картку.

## Менеджер фото (картка → «Редагувати»)

| Клавіші / дії | Дія |
|---|---|
| `⌘` + клік по фото | Додати / зняти виділення одного фото |
| `Shift` + клік | Виділити діапазон від попереднього кліку |
| клік по фото без модифікатора | Зняти все виділення |
| `Esc` | Зняти виділення |
| кнопка «Виділити всі (N)» | Виділити весь поточний набір |

Над виділеними працюють пакетні дії: **✕ Видалити (N)** та **⇄ перенести** в
інший набір (Офіційні / Реальні / Дефекти). Поодинокі дії на плитці (⇄, 🔄, ✕)
ховаються, поки є групове виділення — щоб випадковий клік не зачепив одне фото
замість пачки.

Перетягування плиток (зміна порядку; перше = головне) працює як і раніше.

## Діалоги підтвердження

| Клавіші | Дія |
|---|---|
| `Enter` | Підтвердити |
| `Esc` | Скасувати |

Поки відкрито діалог, картка позаду на клавіші не реагує.

## Поля вводу

| Клавіші | Дія |
|---|---|
| `Enter` | Зберегти значення (швидке редагування ціни, джерела фото тощо) |
| `Esc` | Скасувати редагування поля |

---

### Чому ⌘R раніше «працював через раз»

Застосунок тримає **всі відвідані вкладки змонтованими** (keep-alive — щоб не
губити фільтри й скрол при перемиканні). Обробник «скинути фільтри»
реєструвався один раз при монтуванні кожної сторінки й писав себе в один
глобальний слот. Перемагала та сторінка, яку відкрили **останньою**, — і
залишалась там назавжди. Тому `⌘R` на «Товарах» після візиту в «Клієнти» скидав
фільтри Клієнтів: візуально «нічого не сталось».

Тепер слот перезаписує лише **активна** сторінка, при кожній активації. Той
самий захист додано до `⌘U` та `Esc` на «Товарах» — раніше вони спрацьовували
навіть з чужої вкладки.
